01Arithmetic Operators▸

Core idea An operator is what you use to perform an operation on two operands — add two numbers, compare two values, and so on. Python groups operators into six families: Arithmetic, Relational, Logical, Bitwise, Assignment, Membership.

print(5+6)     # 11
print(5-6)     # -1
print(5*6)     # 30
print(5/2)     # 2.5
print(5//2)    # 2
print(5%2)     # 1
print(5**2)    # 25
★ Remember — the two everyone mixes up
// floor/integer division: "does what normal division does, and then converts the result to an integer." 5 // 2 → 2.5 → truncated to 2.

% modulus: divides and gives the remainder. 5 % 2 → 1. If the first number is smaller than the divisor, modulus just returns the number itself (3 % 10 = 3) — this fact is exactly what powers the digit-extraction trick in section 07.
02Relational Operators▸

Used whenever you compare two things — who's bigger, smaller, equal. These get used in almost every program you'll write from here on.

print(4>5)     # False
print(4<5)     # True
print(4>=4)    # True
print(4<=4)    # True
print(4==4)    # True
print(4!=4)    # False
◆ Not to be confused with
Relational operators (>, ==…) are not the same thing as "conditional operators" — a distinct term some students mix them up with.
03Logical Operators▸ 
print(1 and 0)   # 0
print(1 or 0)    # 1
print(not 1)     # False
OperatorRule
andOutput is 1 only if both are 1. Even one 0 → output 0.
orOutput is 1 if even one is 1. Both 0 → output 0.
notAn inverter — 0 becomes 1, 1 becomes 0.

Python internally maps False→0 and True→1, which is why results of logical expressions come back as booleans built on this 1/0 logic.

04Bitwise Operators▸

These operate on the actual binary bit pattern of numbers.

print(2 & 3)     # 2   -> bitwise AND
print(2 | 3)     # 3   -> bitwise OR
print(2 ^ 3)     # 1   -> bitwise XOR
print(~3)        # -4  -> bitwise NOT
print(4 >> 2)    # 1   -> right shift
print(5 << 2)    # 20  -> left shift

Worked example — 2 & 3, bit by bit

2 = 10    3 = 11

AND each column: 1 & 1 = 1, 0 & 1 = 0 → binary 10 → decimal 2. Same idea for OR (keep 1 if either bit is 1) and XOR.

OpRule (bit by bit)
& AND1 only if both bits are 1
| OR1 if either bit is 1
^ XORSame bits → 0, different bits → 1
~ NOTFlips every bit — 1s become 0s and 0s become 1s
<< left shiftShifts the bit pattern left by N places
>> right shiftShifts the bit pattern right by N places
★ How much you actually need these
Outside AND/OR, bitwise ops (shifts, NOT, XOR) aren't used much in everyday programming or typical data science — maybe in image processing / computer vision. Get familiar with what they do; don't stress about mastering them right now.
05Assignment Operators▸ 
a = 2
a %= 2     # same as: a = a % 2
print(a)

= assigns a value to a variable. Compound forms like +=, -=, *=, /=, %= are shorthand — a += 2 means a = a + 2.

⚠ Coming from C/C++? No ++ / -- here
Python deliberately has no a++ or ++a. The instructor's framing: "there's ambiguity, there's confusion — remember in C, half your time went into figuring out whether ++a and a++ give different output. Python removed the confusion — just one simple notation: a += 2." A real design-philosophy choice, not an oversight.
06Membership Operators▸

in / not in — tells you whether something exists inside something else.

print('D' not in 'Delhi')     # False -> 'D' IS in 'Delhi'
print(1 in [2,3,4,5,6])       # False
★ Why this operator is a big deal
"If this operator didn't exist and someone asked whether 'd' exists inside 'delhi', you'd have to run a loop, touch every character, and only then find out. Here you don't need a loop at all — this is optimized, runs faster than a loop." Same "batteries included" philosophy from Day 1. Works on strings, lists, tuples, sets and dicts — and it's case-sensitive.
◆ Two things NOT covered yet
Python has no dedicated ternary operator — ternary-style logic is done via if-else instead (covered later). There's also an identity operator (is) — different from membership, saved for a future class.
07Applied Program — Sum of Digits▸

The payoff example that shows % and // working together — extract digits one at a time from a number.

number = int(input('Enter a 3 digit number'))

# 345 % 10 -> 5
a = number % 10
number = number // 10

# 34 % 10 -> 4
b = number % 10
number = number // 10

# 3 % 10 -> 3
c = number % 10

print(a + b + c)
Enter a 3 digit number 666
18
  1. number % 10 isolates the last digit (345 % 10 = 5).
  2. number // 10 shrinks the number, dropping that last digit (345 // 10 = 34).
  3. Repeat — mod gives the next digit, floor-divide shrinks again.
  4. Add up all extracted digits.
★ Foreshadowing — this repetition is exactly what loops are for
Doing this by hand for a 6-digit number would mean writing the same two lines six times — "not an efficient way… we'll improve this with a loop" once loops are covered (section 11–12).
08If-Else — Branching▸

Core idea Programs normally run top to bottom. If-else exists to let a program branch — take Option 1 or Option 2 depending on a condition.

⚠ No braces — Python uses indentation
C/C++ wraps blocks in { }. Python has no round brackets, no curly braces, no semicolons — after if condition: you press Enter and Python auto-indents the next line. That indentation is how Python knows what belongs inside the block. "There is only ONE way to write correct code in Python — with proper indentation." Wrong indentation → SyntaxError. Rule to lock in: if and its matching else/elif must sit at the same indentation level, vertically aligned.

Login program — if / elif / else + nested if

email = input('enter email')
password = input('enter password')

if email == 'nitish.campusx@gmail.com' and password == '1234':
  print('Welcome')
elif email == 'nitish.campusx@gmail.com' and password != '1234':
  # give the user one more chance
  print('Incorrect password')
  password = input('enter password again')
  if password == '1234':
    print('Welcome,finally!')
  else:
    print('beta tumse na ho paayega!')
else:
  print('Not correct')
★ Why AND, never OR, for login checks
"You need both email correct AND password correct. If you used OR, what a great website that'd be — it would log you in even with a wrong password just because the email matched!"
★ The general rule for if / elif / else
Two possibilities → if / else. More than two → the middle ones become elif, and the very last one stays else. A nested if is simply an if-else written inside another if/elif/else block — used here to re-check the second password attempt.

10Modules▸
"A module is basically a Python file inside which some functions are already written. You import that file and bring it into your own code."

Core principle: code reusability. "I don't need to write the entire code myself — someone has already written it, I can directly use it." This is exactly how you'll use Scikit-learn, TensorFlow and Keras later in ML — same import mechanism.

import math
math.sqrt(196)        # 14.0

import keyword
print(keyword.kwlist)  # list of all ~33 reserved keywords

import random
print(random.randint(1,100))   # a random int 1-100

import datetime
print(datetime.datetime.now())

help('modules')       # lists every module available in this installation
ModuleShown for
mathsqrt(), factorial(), floor() — ready-made math functions
keywordkwlist — every Python reserved word, programmatically
randomrandint(a,b) — random integer, inclusive both ends
datetimedatetime.now() — current date/time
⚠ datetime.now() on Colab isn't your local time
It shows the timezone of Google Colab's server, not India's — nothing wrong with your code.

Typo'd module name → ModuleNotFoundError. Successful import prints nothing — silence means it worked.

11Loops — While Loop▸
✎ Why loops matter — the Flipkart example
A 78-product listing page isn't 78 hand-built containers — it's one template container, with image/description/price as variables, fetched from a database and rendered inside a loop that runs once per product. Same pattern powers Zomato listings, OLX, hotel booking sites. "A 4th-year student who could only answer 'loops are for printing tables' got rejected in his interview" — always have a real example ready, not just the textbook one.

Python has two loop types: while (condition-driven) and for (sequence-driven).

Multiplication table

i = 1

  i += 1

i stands for iteration — a counter tracking how many times the loop has run. Tip flagged in class: use Python Tutor to step through a loop line by line if the flow ever feels unclear.

★ while…else — a Python-only feature

★ Remember — unusual to Python
"Normally in other languages, else is only used with if. In Python you can attach else to a loop too." The else block runs once the loop finishes normally (its condition becomes False) — it's a natural-completion hook. 
x = 1
while x < 3:
  print(x)
  x += 1
else:
  print('limit crossed')

Number-guessing game — building logic incrementally

★ Problem-solving habit
"Whenever a program feels a bit difficult, break it into smaller pieces." Here: (1) get the compare-and-hint logic working alone first, (2) wrap it in a while so it repeats until correct, (3) attach else for the win message, (4) add a counter for attempts. 
import random
jackpot = random.randint(1,100)

guess = int(input('guess karo'))
counter = 1
while guess != jackpot:
  if guess < jackpot:
    print('galat! guess higher')
  else:
    print('galat! guess lower')

  guess = int(input('guess karo'))
  counter += 1
else:
  print('correct guess')
  print('attempts', counter)

counter starts at 1, not 0 — the user already guessed once before entering the loop, so that first guess needs counting too.

12Loops — For Loop▸ 
for i in range(1,11):
  print(i)                     # 1 through 10 — range's 2nd arg is EXCLUDED

for i in {1,2,3,4,5}:          # for loop works over sets too
  print(i)

for i in 'delhi':              # ...and strings, character by character
  print(i)

for i in range(1,11,2):        # step size -> 1, 3, 5, 7, 9
  print(i)

for i in range(10,0,-1):       # reverse: 10 down to 1
  print(i)
★ range() inclusivity rule
First number included, second number excluded. range(1,11) → 1 through 10. Add a third argument for step size; a negative step (e.g. -1) counts backward.
◆ For loop: Python vs. C/Java
In C-style languages you state three things yourself: starting value, ending condition, increment (i=0; i<10; i++). Python's for loop needs none of that — you just hand it a sequence of values (from range(), a string, a set…) and it loops through them automatically. "A bit different, more flexible, more powerful, and in my opinion a bit easier."

Population decreasing 10%/year, last 10 years

curr_pop = 10000

for i in range(10,0,-1):
  print(i, curr_pop)
